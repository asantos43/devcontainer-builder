# Contributing

After the initial commit, every change must use a dedicated `feat/`, `fix/`, `docs/`, or `chore/` branch and a pull request into `main`. Never commit or push directly to `main`. Do not merge automatically.

Describe the behavior, validation and limitations in every PR. Linux and Windows builds/tests run locally; attach their results. GitHub Actions is exclusively for macOS.

Keep the English and Portuguese guides equivalent. README.md is English; README.pt-BR.md is Portuguese. TODO, CHANGELOG, CONTRIBUTING and SECURITY are English only.

Use MPL-2.0-compatible contributions. Never commit credentials, local environment files or Docker data.
