# DevContainer Builder 0.1.0

First public preview of the desktop Dev Container workbench, licensed under MPL-2.0.

## Features

- Electron, React and Tailwind interface with a VS Code-style workbench, structured editors and English/Portuguese UI.
- Guided creation, nine common development templates, reusable project templates and folder/ZIP/Git import with preview and destination conflict checks.
- Lossless JSONC, Dockerfile and Compose editing, preserving comments and unknown properties, with source/diff review.
- Docker and Podman runtime support, Dev Containers CLI builds, container state controls, xterm logs and interactive shell.
- Git/GitHub initialization and cloning, workspace folders, named volumes, mounts, ports and lifecycle hooks.
- Feature selection, Docker outside/in Docker, SSH-agent assistants and installation options for Claude Code, Codex CLI and OpenCode.
- Built-in themes and declarative VS Code JSON/VSIX/TextMate theme and grammar imports.
- ZIP project export, POSIX/PowerShell start/stop/shell helpers, authenticated cloning into volumes and safe TAR volume backup/restore.
- OS-encrypted credentials, registry authentication, OCI template workflows, Feature updates/comparison and custom container checks.
- Host Trivy SBOM/vulnerability reports for project files and built images, plus opt-in application update checks.

## Downloads and requirements

| Platform | Architecture        | Downloads        | Minimum                          |
| -------- | ------------------- | ---------------- | -------------------------------- |
| macOS    | Intel x64           | DMG and ZIP      | macOS 13 Ventura                 |
| macOS    | Apple Silicon arm64 | DMG and ZIP      | macOS 13 Ventura                 |
| Linux    | x64                 | AppImage and DEB | Desktop glibc 2.31+ distribution |

Require 2 GiB system RAM and 1 GiB free application storage, plus additional capacity for containers/workspaces. Packaged apps include their Node/Electron runtime and the Dev Containers CLI. Container operations require Docker 20.10+ or Podman 4.9+, an active API endpoint and Linux containers. Compose, Git/GitHub, OS credential storage and Trivy have operation-specific prerequisites.

See [complete system requirements](https://github.com/asantos43/devcontainer-builder/blob/v0.1.0/docs/en/system-requirements.md). SHA256SUMS covers the attached distribution assets and supporting files. BUILD-MANIFEST.json records source/build provenance.

## Validation and preview limitations

- macOS Intel and Apple Silicon: 115 unit/domain tests passed, one Linux-specific test skipped; 12 Electron scenarios passed, 12 external integration opt-ins skipped per architecture. DMG/ZIP generation, packaged window, bundled CLI and updater guard passed in [CI](https://github.com/asantos43/devcontainer-builder/actions/runs/39190217041).
- Linux x64: 116 unit/domain tests and 12 Electron scenarios passed; 12 external integration opt-ins skipped in the release follow-up. AppImage/DEB generation and the packaged application/CLI/updater checks passed locally.
- macOS packages are unsigned and not notarized. macOS may block opening this development preview. Signing/notarization and signed update delivery remain pending.
- No Windows binary is included; native Windows packaging/runtime validation is pending.
- Docker Desktop/Podman Machine on macOS/Windows and actual remote SSH/TLS endpoints require separate environment validation. Provider accounts/authentication for AI tools are separate from installing their CLIs.
- This is a prerelease. No stable-release signing guarantee or automatic installation is implied.
