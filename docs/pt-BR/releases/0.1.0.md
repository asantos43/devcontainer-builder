# DevContainer Builder 0.1.0

Primeira prévia pública do aplicativo desktop para Dev Containers, sob licença MPL-2.0.

## Funcionalidades

- Interface Electron, React e Tailwind no estilo VS Code, com editores estruturados e idiomas português/inglês.
- Criação guiada, nove templates comuns, biblioteca de templates de projetos e importação de pasta/ZIP/Git com prévia e verificação de conflitos no destino.
- Edição JSONC, Dockerfile e Compose com preservação de comentários e propriedades desconhecidas, código-fonte e revisão de diferenças.
- Runtime Docker e Podman, builds pela Dev Containers CLI, controles de estado, logs e shell interativo xterm.
- Inicialização e clonagem Git/GitHub, pastas de trabalho, volumes, mounts, portas e hooks de ciclo de vida.
- Seleção de Features, Docker do host/Docker in Docker, assistentes SSH e instalação de Claude Code, Codex CLI e OpenCode.
- Temas integrados e importação declarativa de temas/gramáticas VS Code JSON/VSIX/TextMate.
- Exportação ZIP, scripts POSIX/PowerShell para iniciar/parar/shell, clone autenticado em volumes e backup/restauração TAR com validação de links.
- Credenciais criptografadas pelo SO, autenticação em registries, templates OCI, atualização/comparação de Features e testes personalizados de containers.
- Relatórios SBOM/vulnerabilidades pelo Trivy do host para arquivos/imagens e consulta opcional de atualizações do aplicativo.

## Downloads e requisitos

| Plataforma | Arquitetura         | Downloads      | Mínimo                               |
| ---------- | ------------------- | -------------- | ------------------------------------ |
| macOS      | Intel x64           | DMG e ZIP      | macOS 13 Ventura                     |
| macOS      | Apple Silicon arm64 | DMG e ZIP      | macOS 13 Ventura                     |
| Linux      | x64                 | AppImage e DEB | Distribuição desktop com glibc 2.31+ |

São necessários 2 GiB de RAM e 1 GiB livre para o aplicativo, além de capacidade extra para containers/workspaces. Os pacotes incluem runtime Node/Electron e Dev Containers CLI. Operações de containers exigem Docker 20.10+ ou Podman 4.9+, API ativa e containers Linux. Compose, Git/GitHub, armazenamento de credenciais do SO e Trivy têm requisitos por operação.

Consulte os [requisitos completos](https://github.com/asantos43/devcontainer-builder/blob/v0.1.0/docs/pt-BR/system-requirements.md). SHA256SUMS cobre os arquivos distribuídos e de apoio. BUILD-MANIFEST.json registra a origem do código e dos builds.

## Validação e limites da prévia

- macOS Intel e Apple Silicon: 115 testes unitários/de domínio aprovados, um exclusivo de Linux ignorado; 12 cenários Electron aprovados e 12 integrações opcionais ignoradas por arquitetura. DMG/ZIP, janela empacotada, CLI incluída e bloqueio de instalação antes de download passaram no [CI](https://github.com/asantos43/devcontainer-builder/actions/runs/39190217041).
- Linux x64: 116 testes unitários/de domínio e 12 cenários Electron aprovados; 12 integrações opcionais ignoradas nesta evolução de release. Geração de AppImage/DEB e aplicativo/CLI/atualizador empacotados passaram localmente.
- Pacotes macOS sem assinatura e sem notarização. O sistema pode bloquear a abertura desta prévia de desenvolvimento. Assinatura/notarização e entrega de atualização assinada continuam pendentes.
- Nenhum binário Windows está incluído; validação nativa de empacotamento/runtime permanece pendente.
- Docker Desktop/Podman Machine em macOS/Windows e endpoints SSH/TLS remotos exigem validação separada. Contas/autenticação dos provedores de IA são independentes da instalação das CLIs.
- Esta é uma pré-release. Não implica garantia de assinatura de release estável nem instalação automática.
