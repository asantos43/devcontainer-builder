# Roadmap

## First release
- [ ] Guided creation and existing project import
- [ ] Lossless JSONC and Dockerfile editing, including comments
- [ ] Git/GitHub repositories and workspace mounts
- [ ] Dev Containers CLI runtime, Dockerode logs and terminal
- [ ] Custom tests and portable ZIP export
- [ ] English/Portuguese UI and documentation
- [ ] Local Linux/Windows builds; macOS-only GitHub Actions

## Later
- Docker Compose visual editing and execution
- Docker in Docker and remote Docker endpoints
- Registry authentication and OCI templates
- SSH agent and secrets assistants
- Clone into volumes and volume backup/restore
- Feature updates and configuration comparison
- SBOM, vulnerability scanning and automatic application updates
